## Responses API

:star: **Responses API** is the bring together of two previously seperate APIs (ChatCompletetions and Assistants).
> Unified API combining ChatCompletions and Assistants – stateful, multi-turn, ideal for conversational AI

📎 The **OpenAI‑compatible client** in Foundry is the Foundry SDK’s built‑in way to perform **simple inference** using the same API shape as the OpenAI SDK.

---

## 📦 Setup

```python
from openai import OpenAI

openai_client = OpenAI(
    base_url="https://<your-endpoint>.openai.azure.com/openai/v1/",
    api_key="<your-api-key>"
)
```

For async: `from openai import AsyncOpenAI`

---

## 🚀 Basic Usage

### Simple response, with instructions, controls and properties


```python
# Generate a response using the OpenAI-compatible client
response = openai_client.responses.create(
    model="gpt-4.1",
    instructions="You are a helpful AI assistant...",
    input="Write a creative story about AI.",
    temperature=0.8,                # 0.0–2.0, higher = more creative
    max_output_tokens=200           # limit response length
)
# Display the response
print(f"Response: {response.output_text}") # Generated Text
print(f"ID: {response.id}") # unique id e.g.resp_047c3dde707dcfb3006a6a04b013bc819791cf7e853a35131d
print(f"Tokens: {response.usage.total_tokens}") # token count e.g. 562
print(f"Status: {response.status}") # e.g. completed
print(f"Temprature: {response.temprature}") # e.g. 1.0
```

## 💬 Multi-Turn Conversations

### Using `previous_response_id` (recommended)

```python
# Turn 1
response1 = openai_client.responses.create(
    model="gpt-4.1",
    instructions="You are a helpful AI assistant...",
    input="What is machine learning?"
)

# Turn 2 – pass previous ID for context
response2 = openai_client.responses.create(
    model="gpt-4.1",
    instructions="You are a helpful AI assistant...",
    input="Can you give me an example?",
    previous_response_id=response1.id   # links conversations
)
```


### Interactive chat loop

```python
last_response_id = None
while True:
    user_input = input("You: ")
    if user_input.lower() == "quit":
        break
    response = openai_client.responses.create(
        model="gpt-4.1",
        instructions="You are a helpful AI assistant...",
        input=user_input,
        previous_response_id=last_response_id
    )
    print("Assistant:", response.output_text)
    last_response_id = response.id
```

## 🧠 Manual Conversation Chaining

Build history yourself for full control – useful for pruning, storage, or custom context

```python
conversation_history = [
    {"type": "message", "role": "user", "content": "What is machine learning?"}
]

response1 = openai_client.responses.create(
    model="gpt-4.1",
    input=conversation_history
)
conversation_history += response1.output   # append assistant response

conversation_history.append({
    "type": "message",
    "role": "user",
    "content": "Can you give me an example?"
})

response2 = openai_client.responses.create(
    model="gpt-4.1",
    input=conversation_history
)
```

## ⚡ Streaming

### Sync streaming

```python
stream = openai_client.responses.create(
    model="gpt-4.1",
    input="Write a short story about a robot learning to paint.",
    stream=True
)
for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
    elif event.type == "response.completed":
        response_id = event.response.id
```


### Async streaming

```python
async def stream_response():
    stream = await client.responses.create(
        model="gpt-4.1",
        input="Write a haiku about coding.",
        stream=True
    )
    async for event in stream:
        print(event, end="", flush=True)

asyncio.run(stream_response())
```

## 📐 Context Window

What's included in each request:
- System instructions
- Current prompt
- Conversation history (previous user + assistant messages)
- Tool schemas (functions, OpenAPI, MCP)
- Tool outputs (search, code interpreter, files)
- Retrieved memory/documents (RAG, file search)

> All concatenated and tokenized together every request – SDK manages state but **doesn't** reduce token cost automatically

---

## 🔑 Key Parameters

| Parameter | Description |
|-----------|-------------|
| `model` | Model deployment name (Azure OpenAI or Foundry direct) |
| `input` | User prompt (string or message history list) |
| `instructions` | System instructions to guide model behavior |
| `temperature` | Randomness 0.0–2.0 (higher = more creative) |
| `max_output_tokens` | Max tokens in response |
| `top_p` | Alternative to temperature |
| `previous_response_id` | Link to previous response for multi-turn context |
| `stream` | `True` for incremental output |

# ChatCompletions API

> Established API for generative AI – stateless, requires manual context tracking. Recommended for code maintenance and cross-platform compatibility.

## 🚀 Basic Usage

Messages are passed as a **collection of message objects** in JSON format:

```python
completion = openai_client.chat.completions.create(
    model="gpt-4o",                      # Your model deployment name
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "When was Microsoft founded?"}
    ]
)
print(completion.choices[0].message.content)
```

### Message Roles

| Role | Purpose |
|------|---------|
| `system` | Sets assistant behavior / instructions |
| `user` | User prompt / question |
| `assistant` | Previous model responses (for context) |

---

## 💬 Retaining Conversational Context

> ⚠️ **Unlike the Responses API, ChatCompletions is stateless** – you must manually track previous prompts and responses.

## 🔁 Interactive Chat Loop

```python
conversation_messages = [
    {"role": "system", "content": "You are a helpful AI assistant."}
]

print("Assistant: Enter a prompt (or type 'quit' to exit)")

while True:
    user_input = input("\nYou: ")
    if user_input.lower() == "quit":
        print("Assistant: Goodbye!")
        break

    # Add user message
    conversation_messages.append(
        {"role": "user", "content": user_input}
    )

    # Get completion
    completion = openai_client.chat.completions.create(
        model="gpt-4o",
        messages=conversation_messages
    )
    assistant_text = completion.choices[0].message.content
    print("\nAssistant:", assistant_text)

    # Append assistant response for next turn
    conversation_messages.append(
        {"role": "assistant", "content": assistant_text}
    )
```

**Sample output**:
```
Assistant: Enter a prompt (or type 'quit' to exit)
You: When was Microsoft founded?
Assistant: Microsoft was founded on April 4, 1975 in Albuquerque, New Mexico, USA.
You: Who founded it?
Assistant: Microsoft was founded by Bill Gates and Paul Allen.
You: quit
Assistant: Goodbye!
```

| Parameter | Description |
|-----------|-------------|
| `model` | Model deployment name (Azure OpenAI or Foundry direct) |
| `messages` | List of message objects with `role` and `content` |
| `temperature` | Randomness 0.0–2.0 (optional) |
| `max_tokens` | Max tokens in response (optional) |
| `stream` | `True` for incremental output (optional) |

---

## 📊 Responses API vs ChatCompletions API

| Feature | Responses API | ChatCompletions API |
|---------|---------------|---------------------|
| **Statefulness** | ✅ Built-in (`previous_response_id`) | ❌ Manual tracking required |
| **Context tracking** | Automatic | Manual message list |
| **Recommendation** | For new projects | For maintenance & cross-platform |
| **History submission** | Handled by SDK | Entire history submitted each turn |

---

## ⚠️ Important Notes

- Each new user prompt and completion must be **added to the conversation list** manually
- The **entire conversation history** is submitted in **every** API call
- Well-established in the generative AI ecosystem – useful to be familiar with
- Works with both Azure OpenAI models and Foundry-hosted models
