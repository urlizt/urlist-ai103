# Domain 1: Plan and manage an Azure AI solution (20-25%)

## **AI Overview**
- AI = software that performs **human‑like tasks** (interpretation, reasoning, generating responses).  
- Modern AI uses **machine learning models** trained on large datasets to learn patterns and semantics.

## **Core AI Capability Areas**

### **1. Generative AI & Agents**
- Uses **LLMs** to generate text, code, content.  
- Foundation for **agentic AI**: autonomous agents that follow instructions and use tools to complete tasks.

### **2. Natural Language Processing (NLP)**
- Traditional field focused on understanding text.  
- Includes tasks like **classification, sentiment analysis, summarization, term‑frequency models**.  
- Some workloads still benefit from classic NLP over LLMs.

### **3. Computer Speech**
- Speech recognition + speech synthesis.  
- Enables transcription, translation, conversational interfaces, read‑aloud features.

### **4. Computer Vision**
- Interprets images, video, and live streams.  
- Used for object detection, automated checkout, image/video generation (via multimodal models).

### **5. Information Extraction**
- Combines language, vision, and speech to pull structured data from documents, forms, images, audio.  
- Example: extracting receipt details automatically.

## **What Microsoft Foundry Is**
- A **platform for AI development on Azure** that provides project organization, resource management, and AI tooling
- Recommended for all but the simplest AI solutions due to its integrated capabilities

## **Core Components**

### **Foundry Portal**
- A **web‑based interface** for developing and managing AI projects
- Supports model deployment/testing, agent creation, tool configuration, resource management, and retrieving endpoints/keys

### **Foundry SDK**
- Enables **programmatic creation and management** of AI solutions, including CI/CD automation

## **Projects & Resources**

### **Projects**
- Central containers for **resource connections, data, code, and solution assets** 
- Each project belongs to a single Foundry resource providing compute, storage, and AI tools
- A resource can host multiple child projects, with one designated as default 

### **Project Assets**
- **Models:** LLM deployments from the Foundry Models catalog; accessible via Foundry or Azure OpenAI endpoints
- **Agents:** Autonomous AI entities combining an LLM, instructions, and tools; built using the Foundry Agent service 
- **Tools:** Built‑in (search, code interpreter) or custom/third‑party via MCP connections; includes Foundry Tools suite for text, speech, translation, and content understanding 
- **Knowledge:** Agents can connect to knowledge stores; Foundry IQ provides a single MCP‑based knowledge connection for multiple sources 

## **Why Projects Matter**
- They provide the right level of **centralization and capability** for generative AI apps and agents with minimal admin overhead 

## **Portal Notes**
- The module covers the **latest project architecture**; older “classic” projects use a hub‑based model 
- The portal is transitioning to a **new interface**, and some tasks may not yet be supported there

# **Foundry Tools — Summary**

Microsoft Foundry provides a set of **prebuilt, off‑the‑shelf AI tools** you can integrate into applications to handle common AI tasks more predictably and cost‑effectively than relying solely on generative AI agents.

## **Available Tools**

### **Azure Language**
- Text analysis: entity extraction, sentiment analysis, summarization 
- Supports conversational language models and Q&A solutions 

### **Azure Speech**
- Text‑to‑speech and speech‑to‑text  
- Real‑time speech for conversational apps and agents  
### **Azure Translator**
- High‑quality translation across many languages  

### **Azure Document Intelligence**
- Extract fields from documents (invoices, receipts, forms) using prebuilt or custom models 

### **Azure Content Understanding**
- Multimodal content analysis for forms, documents, images, video, and audio streams  

## **How to Use Foundry Tools**
- Connect client apps to tool‑specific endpoints in your Foundry resource using project keys or token‑based auth  
- Use tool‑specific APIs and SDKs to access functionality  
- Some tools include UI support for configuration and testing in the Foundry portal 

## **Notes**
- Azure Tools were previously known as **Azure AI Services** and **Azure Cognitive Services**; older names may still appear in APIs/SDKs  
- You can still provision them as standalone Azure resources, but **new projects should use Foundry Tools** within a Foundry resource
