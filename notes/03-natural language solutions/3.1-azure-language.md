# Analyze text with Azure Language

Azure Language in Foundry Tools enables you to create intelligent apps and services that extract semantic information from text.

## 🔹 Core capabilities

- **Language detection** — identify the language of input text  
- **Named entity recognition** — extract people, places, organizations, dates, etc.  
- **PII extraction** — detect and redact personal information  
- Additional legacy features: **sentiment analysis**, **summarization**, **key phrase extraction**, etc.

### 🔹 Using Azure Language in Foundry Tools

1. **Provision a Foundry resource** in your Azure subscription  
2. Use the resource’s **endpoint + key** or **Microsoft Entra ID identity** to authenticate  
3. Submit requests via **REST (JSON)** or an **SDK** (Python, C#, JavaScript, etc.)

### 🔹 Authentication

- **Key‑based**  
  - Use the key shown in the Foundry portal  
  - Project endpoint = resource endpoint + `/api/projects/{project_name}`  

- **Microsoft Entra ID**  
  - Recommended for production  
  - Uses `DefaultAzureCredential` to authenticate without storing keys

### 🔹 Python examples

The page shows how to create a `TextAnalyticsClient` using:

```python
# run "pip install azure-ai-textanalytics" first to install the package 
from azure.core.credentials import AzureKeyCredential
from azure.ai.textanalytics import TextAnalyticsClient

# Create client using endpoint and key
credential = AzureKeyCredential("YOUR_FOUNDRY_RESOURCE_KEY")
client = TextAnalyticsClient(endpoint="YOUR_FOUNDRY_RESOURCE_ENDPOINT", 
                             credential=credential)
```

Both approaches initialize a client that can send text‑analysis requests to the Foundry resource.

## Detect Language

**Azure Language detection** identifies the language used in text and returns a confidence score. Useful when the input language is unknown, such as user-generated content or multilingual chat applications. ([Microsoft Learn][1])

### 🔑 Key concepts

| Concept              | Remember                                              |
| -------------------- | ----------------------------------------------------- |
| **API**              | Azure Language detection API                          |
| **Input**            | Documents or individual phrases                       |
| **Output**           | Detected language + ISO 639-1 code + confidence score |
| **Confidence**       | `0` to `1`; closer to `1` = greater confidence        |
| **Document limit**   | **5,120 characters per document**                     |
| **Batch limit**      | Up to **1,000 document IDs** per collection           |
| **Unknown language** | Returns `(unknown)` with confidence `0`               |

### Python

The SDK uses `TextAnalyticsClient.detect_language()`:

```python
documents = ["Hello World!", "Bonjour le monde!"]

response = client.detect_language(documents=documents)

for doc in response:
    print(doc.primary_language.name)
    print(doc.primary_language.iso6391_name)
    print(doc.primary_language.confidence_score)
```

Example results:

```text
English → en → 0.9
French  → fr → 0.98
```

### ⚠️ Exam points

**Mixed-language text:**
If a document contains multiple languages, the service returns the language with the **largest representation**, but confidence may be lower because the input is ambiguous.

**Unparseable text:**
If encoding or other issues prevent analysis:

```text
Language: (unknown)
ISO code: (unknown)
Confidence: 0
```

### 🧠 Revision snapshot

> **Detect Language = language + ISO code + confidence**
>
> **Confidence:** `0–1`, higher = more confident
> **Document:** max **5,120 characters**
> **Batch:** max **1,000 IDs**
> **Mixed languages:** dominant language returned, potentially lower confidence
> **Can't determine:** `(unknown)`, score `0`
