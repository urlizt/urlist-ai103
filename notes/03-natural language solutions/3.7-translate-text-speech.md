# Translate Text and Speech

Microsoft provides two main translation services:

| Service              | Use                       |
| -------------------- | ------------------------- |
| **Azure Translator** | Translate text            |
| **Azure Speech**     | Translate spoken language |

### Azure Translator

Designed specifically for multilingual text and supports:

* Translation across many languages
* Transliteration
* Document translation
* Custom translation models
* LLM-based translation

### Azure Speech

Can perform:

```text
Speech → Text translation
Speech → Speech translation
```

## 2. Translate Text with Azure Translator

Azure Translator supports **90+ languages** and provides both REST APIs and SDKs.

### Python SDK

```python
from azure.core.credentials import AzureKeyCredential
from azure.ai.translation.text import TextTranslationClient

client = TextTranslationClient(
    credential=AzureKeyCredential("FOUNDRY_KEY"),
    endpoint="FOUNDRY_ENDPOINT"
)
```

### Translate

The important method is:

```python
client.translate(
    body=input_text_elements,
    to_language=["fr", "en"]
)
```

You can:

* Specify the source language
* Let Translator **detect the source language automatically**
* Translate into **multiple target languages**

### Example

```text
Hola
   ↓
French → Bonjour
English → Hello
```

### 🧠 Remember

> **`translate()` = translate language**

---

## 3. Transliteration

**Translation ≠ transliteration.**

### Translation

Changes the **language**:

```text
こんにちは
      ↓
Hello
```

### Transliteration

Keeps the **language**, but changes the **writing system**:

```text
こんにちは
      ↓
Kon'nichiwa
```

This is useful when users need to read a language using a different script.

### Python

```python
client.transliterate(
    body=input_text_elements,
    language="ja",
    from_script="Jpan",
    to_script="Latn"
)
```

### 🧠 Exam distinction

> **Translation = language changes**
> **Transliteration = script changes**

This one is worth memorising.

## 4. Translate Speech

Azure Speech provides a **Speech Translation API**.

The main object is:

```text
TranslationRecognizer
```

configured using:

```text
SpeechTranslationConfig
```

### Architecture

```text
🎤 Speech
   ↓
TranslationRecognizer
   ↓
Speech recognition
   ↓
Translation
   ↓
🇫🇷 French
🇯🇵 Japanese
...
```

### Configure

```python
translation_cfg = speech_sdk.translation.SpeechTranslationConfig(
    subscription="FOUNDRY_KEY",
    endpoint="FOUNDRY_ENDPOINT"
)

translation_cfg.speech_recognition_language = "en-US"

translation_cfg.add_target_language("fr")
translation_cfg.add_target_language("ja")
```

Then specify the audio:

```python
audio_cfg = speech_sdk.AudioConfig(
    use_default_microphone=True
)
```

And create:

```python
translator = speech_sdk.translation.TranslationRecognizer(
    translation_config=translation_cfg,
    audio_config=audio_cfg
)
```

## 5. Speech → Multiple Text Languages

A particularly useful capability is translating **one spoken language into multiple target languages simultaneously**.

```text
           English speech
                 ↓
        TranslationRecognizer
          ↙       ↓       ↘
       French   Japanese   German
```

Example:

```text
User says:
"Hello everyone"

French:
"Bonjour tout le monde"

Japanese:
"こんにちは、皆さん"
```

### 🧠 Key point

`add_target_language()` can be called multiple times.

# 6. Speech → Speech

You can also produce **spoken translations**.

There are **two approaches**.

## Approach 1: Manual synthesis

This is effectively two operations:

```text
Speech
  ↓
TranslationRecognizer
  ↓
Translated text
  ↓
SpeechSynthesizer
  ↓
Translated speech
```

You use:

* `TranslationRecognizer`
* `SpeechSynthesizer`

You can choose a **language-specific voice**.

Example:

```python
voices = {
    "fr": "fr-FR-HenriNeural",
    "ja": "ja-JP-NanamiNeural"
}
```

### Advantage

You can generate speech for **multiple target languages**.

---

## Approach 2: Event-based synthesis

For **1:1 translation**:

```text
One source language
        ↓
One target language
```

you can use the translation recognizer's **`Synthesizing` event**.

The translated audio arrives as an audio stream.



## 🧠 AI-103 Revision Snapshot

| **Topic**                        | **Flow**                                                                                 | **Key class / method**                            |
| -------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------- |
| **Text translation**             | Azure Translator → Text → translated text                                                | `TextTranslationClient` → `translate()`           |
| **Transliteration**              | Azure Translator → Script → different script                                             | `transliterate()`                                 |
| **Speech translation**           | Azure Speech → `TranslationRecognizer` → Speech → translated text                        | `SpeechTranslationConfig`                         |
| **Speech-to-speech translation** | Speech → `TranslationRecognizer` → Translation → `SpeechSynthesizer` → Translated speech | **Event-based synthesis** for **1:1 translation** |

## ⚠️ Exam traps

| Question                          | Answer                            |
| --------------------------------- | --------------------------------- |
| Text translation?                 | **Azure Translator**              |
| Speech translation?               | **Azure Speech**                  |
| Translate text method?            | `translate()`                     |
| Change writing system?            | `transliterate()`                 |
| Speech translation class?         | `TranslationRecognizer`           |
| Speech translation configuration? | `SpeechTranslationConfig`         |
| Audio input configuration?        | `AudioConfig`                     |
| Multiple target languages?        | `add_target_language()`           |
| Speech → translated speech?       | Translation + `SpeechSynthesizer` |
| Event-based synthesis?            | **1 source → 1 target only**      |
| Source language                   | `speech_recognition_language`     |
| Target language                   | `add_target_language()`           |

> Important limitation - **Event-based synthesis cannot be used for multi-language translation.**

### ⭐ One-line memory hook

> **Translator handles text; Speech handles spoken language; `translate()` changes language, `transliterate()` changes script, and `TranslationRecognizer` handles speech translation.**
