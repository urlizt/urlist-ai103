# Analyze images with Content Understanding

## Module goal

Use **Azure Content Understanding** in Microsoft Foundry to turn **unstructured images into structured data** using prebuilt or custom analyzers.

```text
Image
  ↓
Content Understanding
  ↓
Analyzer
  ↓
Extract / Classify / Generate
  ↓
Structured data
```

## 1. What is Content Understanding?

Content Understanding is a **Foundry Tool** that uses generative AI to process:

* Documents
* Images
* Video
* Audio

It transforms unstructured content into **structured, actionable output**.

### Core components

| Component              | Purpose                                       |
| ---------------------- | --------------------------------------------- |
| **Input**              | Document, image, video or audio               |
| **Analyzer**           | Defines how content is processed              |
| **Content extraction** | OCR, transcription, layout detection          |
| **Field extraction**   | Produces structured key/value data            |
| **Confidence score**   | Reliability of each extracted value, 0–1      |
| **Grounding**          | Shows where the value came from in the source |
| **Structured output**  | Markdown or JSON                              |

## 2. Analyzers

There are two types:

### Prebuilt analyzers

Ready-made for common scenarios:

```text
prebuilt-image
prebuilt-receipt
prebuilt-invoice
prebuilt-idDocument
```

### Custom analyzers

Define your own **field schema** for a specific business scenario.

```text
Image
 ↓
Custom analyzer
 ↓
Your field schema
 ↓
Structured output
```

## 3. Field extraction methods

A field schema can use three methods:

| Method       | Purpose                                     | Example                    |
| ------------ | ------------------------------------------- | -------------------------- |
| **extract**  | Extract information directly from the image | Product name               |
| **classify** | Categorize into predefined values           | `new` / `used` / `damaged` |
| **generate** | Generate information from analysis          | Image description          |

This is a particularly exam-friendly distinction.

## 4. Analyze images with Python

Install:

```python
pip install azure-ai-contentunderstanding
```

Key client:

```python
ContentUnderstandingClient
```

Analysis:

```python
client.begin_analyze()
```

The operation is asynchronous and returns a **poller**:

```python
poller = client.begin_analyze(...)
result = poller.result()
```

### Authentication

Can use:

```python
AzureKeyCredential
```

or:

```python
DefaultAzureCredential
```

## 5. Analysis results

Results can contain:

```text
markdown
fields
source
```

### Markdown

A textual representation of the image, useful for:

* Search
* RAG

### Fields

Structured values matching your schema.

Each field can include:

```text
value
confidence
```

### Grounding / source

Identifies the **specific region of the image** where the extracted value was found.

## 6. Confidence scores

Scores range from **0 to 1**.

| Score       | Meaning                                             |
| ----------- | --------------------------------------------------- |
| **0.9+**    | High confidence → suitable for automated processing |
| **0.7–0.9** | Medium → consider human review                      |
| **<0.7**    | Low → manual verification recommended               |

This enables a **human-in-the-loop** workflow:

```text
Extract
   ↓
Confidence?
 ┌───────────────┐
 High            Low
 ↓                ↓
Automate      Human review
```

### 🔑 Exam traps

* **Grounding** = identifies **where** the extracted value came from.
* **Confidence** = indicates **how reliable** the extraction is.
* `extract` ≠ `classify` ≠ `generate`.
* `prebuilt-receipt` → receipts.
* `prebuilt-invoice` → invoices.
* `prebuilt-idDocument` → identity documents.
* `begin_analyze()` starts analysis; `poller.result()` gets the result.
* Content Understanding is broader than simple OCR. It can **extract, classify and generate structured information**.

### 🧠 Memory hook

> **Analyzer → Schema → Extract/Classify/Generate → Confidence + Grounding → Structured data**
