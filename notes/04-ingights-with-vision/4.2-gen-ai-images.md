# Generate images with Azure OpenAI

> **Current note for AI-103:** Microsoft has moved beyond DALL-E 3. `gpt-image-*` models are the current image-generation family. DALL-E 3 was retired on **March 4, 2026**.

## 1. Image generation

Image generation uses a generative AI model to turn a **text prompt into an image**.

```text
Text prompt
     ↓
Image generation model
     ↓
Generated image
```

The model interprets the prompt and creates the requested visual content.

## 2. Image generation models

The current Azure OpenAI image-generation models are in the **GPT-image** family.

Examples:

```text
gpt-image-1
gpt-image-2
```

For AI-103, remember the distinction:

| Model                | Purpose                  |
| -------------------- | ------------------------ |
| GPT text model       | Generate text            |
| GPT multimodal model | Understand text + images |
| **GPT-image model**  | **Generate images**      |

## 3. Generate an image with Python

The OpenAI Python SDK provides the image generation API.

```python
from openai import AzureOpenAI

client = AzureOpenAI(...)

result = client.images.generate(
    model="gpt-image-1",
    prompt="A bear walking through a forest",
    size="1024x1024",
    quality="high",
    n=1
)
```

### Key method

```python
client.images.generate()
```

### Key parameters

| Parameter            | Purpose                            |
| -------------------- | ---------------------------------- |
| `model`              | Deployed image model               |
| `prompt`             | Description of desired image       |
| `size`               | Image dimensions                   |
| `quality`            | `low`, `medium`, `high`            |
| `n`                  | Number of images                   |
| `output_format`      | PNG or JPEG                        |
| `background`         | Can support transparent background |
| `output_compression` | JPEG compression level             |

## 4. Image response

GPT-image models return image data, including **Base64-encoded image data**.

```python
# Generate an image
img_results = client.images.generate(
    model="FLUX.1-Kontext-pro",
    prompt="A robot eating a cheeseburger.",
    n=1,
    size="1024x1024",
)

# Save the generated image
image_data = base64.b64decode(img_results.data[0].b64_json)
with open("image.png", "wb") as image_file:
    image_file.write(image_data)
```

The playground can also provide generated **Python and cURL code** for reproducing the request programmatically.

Higher quality generally means greater generation cost/time.

## 5. Content filtering

Azure OpenAI applies **content moderation** to image generation.

If the prompt or generated content violates the applicable safety policy:

```text
Prompt
  ↓
Safety/content filter
  ↓
Blocked
```

The application should handle content-policy errors appropriately rather than assuming every prompt produces an image. Humanity continues to discover that "make literally anything" requires rules. 🤖
