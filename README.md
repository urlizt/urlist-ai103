## 🧩 How These Summaries Are Generated
All summaries in this repo are created using a persistent Copilot memory configuration that includes:

### **Formatting Rules**
- Reuse images from the page  
- Include diagrams when present  
- Highlight definitions in bold  
- Add a “Key Exam Traps” section  

### **Structural Rules**
- Add a 5‑point Rapid Recall section  
- Add comparison tables when multiple concepts appear  
- Include mnemonics for each major section  

### **Style Rules**
- Keep summaries under 300 words  
- Use ultra‑compressed bullets  
- Always include a one‑sentence TL;DR  

These preferences are stored in Copilot’s memory, so every summary is generated consistently without needing to paste prompts.
